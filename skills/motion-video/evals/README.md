# motion-video 스킬 시험

`reference-plan/` — 레퍼런스 영상(ref.mp4) 하나를 둔 빈 폴더에서 `prompt.md` 를 헤드리스로 실행하고 `grade.py <폴더> <claude -p --output-format json 결과>` 로 8개 항목을 채점한다.
레퍼런스는 아무 짧은 모션 영상이면 된다 (2026-11-12 시험은 24fps·2프레임 홀드·컷/디졸브/검은 페이드·그레인이 든 12초 합성 영상).

| 2026-11-12 | 통과 | 시간 | 비용 |
|---|---|---|---|
| 스킬 있음 | 8/8 | 108초 | $0.54 |
| 스킬 없음 | 2/8 | 110초 | $0.46 |

스킬 없음도 계획 자체는 좋았다(눈으로 프레임 분석, 진폭으로 회복을 보이는 연출). 스킬이 더한 것: 측정값 근거(실효 12fps, 디졸브 12프레임 — 눈 추정은 0.3초로 틀림), `const FX` 효과 사양표, 장면별 카메라, ±20% 합격 조건, storyboard.md, 글자 유지 시간 자체 점검. 채점의 일부는 단어 매칭이라 점수 차이는 실제보다 크게 보인다.
