# 나의 강의 영상 스타일 가이드

기준 구현: `templates/example-lecture/` (45초 6장면 데모). 새 영상은 이 토큰과 패턴에서 출발해 주제에 맞게 바꾼다.

## 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| ground | `#0b1020` + 우상단 `#1a2550` 방사형 그라데이션 | 배경 (루트 `#bg`) |
| ink | `#f4f1ea` | 본문 글자 |
| muted | `#8a93b8` | 보조 설명, 라벨 |
| panel | `#121a36`, 테두리 `#26315e` | 카드, 노드, 터미널 |
| accent | `#ffb547` (앰버) | 핵심 단어 1개, 강조 |
| accent2 | `#4fd1c5` (청록) | 진행·연결선·완료 ✓ |
| accent3 | `#ff6b6b` (코랄) | 경고·제약·세 번째 항목 |

- 폰트: Pretendard 400/700/900 (`assets/fonts/`), 각 장면 파일에 `@font-face` 선언 필수
- 크기: 장면 제목 76px/900, 큰 문장 88~92px/900, 본문 34~46px/700, **최소 28px** (모바일 가독성)
- 좌측 여백 200px, 제목 top 110~150px. 내용은 90% 안전영역(가로 96~1824, 세로 54~1026) 안에

## 모션 규칙

- 등장: `fromTo` + `power3.out` 0.4~0.6초, y 16~30px 또는 blur 8→0. **`from`은 쓰지 않는다**(되감기 시 어긋남)
- 강조 팝: `back.out(1.8~2.5)`; 떨어져 쌓이는 것: `bounce.out`
- 장면 끝 0.35초 전에 `#root` opacity 0 (`power2.in`)으로 정리
- 한 번에 하나: 다이어그램은 완성본을 한꺼번에 띄우지 않고 **말하는 순서대로 한 부분씩** 자란다
- 숫자는 카운트업(onUpdate로 textContent), 원은 `stroke-dashoffset`으로 그리기
- 0초 프레임에 제목이나 핵심 이미지가 이미 보여야 한다(썸네일)

## 장면 shape 레퍼런스 (templates/example-lecture/compositions/)

| shape | 파일 | 핵심 기법 |
|---|---|---|
| transform | `hook.html` | 막대 scaleX 접힘 → 코드 줄 stagger 등장 |
| cycle | `loop.html` | SVG 원 dashoffset 4단계 + 노드 테두리 플래시 |
| checklist-terminal | `prep.html` | 명령 줄 → 0.4초 뒤 ✓ 팝, 옆에 큰 숫자 메모 |
| stack | `stack.html` | 층이 위에서 떨어져 쌓임, 이전 층 dim, 별 개수 카운트업 |
| axis | `license.html` | 그라데이션 축 scaleX → 핀이 위치에 떨어짐 |
| converge | `outro.html` | 칩 3개가 가운데로 모이며 사라짐 → 결론 한 줄 |

## 금지 패턴 (AI 티 나는 것)

- 글머리표 슬라이드, 아이콘을 원 안에 넣은 카드 3개 나란히
- 내레이션을 화면에 글자 그대로 반복 (화면은 **키워드·구조**, 목소리는 **문장**)
- 원문에 없는 숫자, 범례(legend) 상자, 이모지로 아이콘 대체
- 모든 장면이 같은 등장 효과 — shape마다 다른 그림을 쓴다

## 참고한 프롬프트 패턴 (skillry Opus 5.5 갤러리)

설명형 영상 프롬프트들의 공통점: "전문 모션 디자이너 역할", "장면 N개와 각 장면의 역할을 명시", "굵은 글자·부드러운 전환·브랜드 색", "단일 HTML로". 이 스킬은 그걸 강의용으로 고정한 것:

```
전문 모션 디자이너로서 source/source.md를 60초 강의 영상으로 만들어줘.
핵심 아이디어 하나: <한 문장>. 대상: <누구>.
장면 6~8개: 질문(hook) → 개념 → 예시 하나를 끝까지 → 정리 한 줄.
edu-video 스타일 가이드의 색·폰트·shape를 쓰고, 장면마다 다른 shape를 골라줘.
```
